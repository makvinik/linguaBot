Структура проекта:

- lingua_core.py - Основной код взаимодействия с моделью: промпт, формирование запросов, вызов модели и получение ответов.
- eval_grammar.py - Оценщик качества ответов модели. Сравнивает ответы с эталонными примерами, рассчитывает метрики и формирует Excel-отчёты.
- grammar_rules.json - Каталог из 95 грамматических правил с идентификаторами rule_id. Используется для классификации ошибок.
- linguabot_test_set_.jsonl - Контрольный набор из 169 тестов для оценки грамматических исправлений, выбора правил и качества ответов.
- results_baseline_v10.xlsx - Результаты baseline
- scenarios.json - Сценарии
- LinguaBot_спецификация_поведения_модели - Описание правил, частично промптов для модели. Что делает, как себя ведет при сценариях, в свободном диалоге, как исправляет ошибки и тд
